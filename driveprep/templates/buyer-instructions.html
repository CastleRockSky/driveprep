This drive is blank on purpose
Every sector was overwritten with zeros and then read back to confirm it, so there is no partition table and no filesystem on it. Your computer will report it as uninitialised, unallocated, or “not readable”. That is expected and is not a fault — it takes about two minutes to set up, using software already built into your operating system. No downloads are needed.
Windows 10 / 11
  1. Connect the drive and wait a few seconds.
  2. Right-click the Start button and choose Disk Management.
  3. An Initialize Disk box usually appears. Choose GPT and click OK.
    If it does not appear, find the disk labelled “Not Initialized” in the lower panel, right-click its grey name box on the left, and choose Initialize Disk.
  4. Right-click the black Unallocated bar and choose New Simple Volume.
  5. Click Next through the wizard. Choose a file system when asked (see below) and give the drive a name.
  6. Click Finish. The drive now appears in File Explorer.
macOS
  1. Connect the drive. If macOS says the disk is not readable, click Initialize — that opens Disk Utility.
  2. Otherwise open Disk Utility from Applications › Utilities.
  3. In the View menu choose Show All Devices.
    This step matters. Without it a blank drive is not listed at all.
  4. Select the drive itself in the sidebar — the outer entry with the model name, not an indented volume beneath it.
  5. Click Erase. Set Scheme to GUID Partition Map, pick a format (see below), and name the drive.
  6. Click Erase. The drive appears on your desktop and in Finder.
Linux
  1. Connect the drive.
  2. Open Disks (GNOME Disks), select the drive, then use the ⋮ menu › Format Disk and choose GPT.
  3. Click + to create a partition, choose a size and file system, and confirm.
  4. Or from a terminal, replacing sdX with the drive:
sudo parted /dev/sdX mklabel gpt
sudo parted -a opt /dev/sdX \
     mkpart primary ext4 0% 100%
sudo mkfs.ext4 /dev/sdX1
Check the device name with lsblk first. Writing to the wrong one destroys data.
Which file system should I choose?
ChoiceUse it when Read / write support
exFAT You want the drive to work everywhere. Best all-round choice for a portable drive. Windows, macOS and Linux, read and write
NTFS The drive will live on a Windows PC. Windows read/write; macOS read-only without extra software
APFS or Mac OS Extended The drive will live on a Mac, or you use Time Machine. macOS only
ext4 The drive will live on a Linux machine. Linux; not readable by Windows or macOS as shipped
Looking after it
  • It is a mechanical drive. Do not move, knock or tip it while the platters are spinning, and let it stop before unplugging.
  • Eject before unplugging — “Safely Remove” on Windows, drag to the Bin or press Eject on macOS, umount on Linux. Pulling it mid-write can lose data.
  • Give it air. Do not run it under a blanket, on carpet, or stacked against other drives during long copies.
  • This is a used drive, and it has a service history. The report on the previous page shows its actual measured condition. Keep a second copy of anything you cannot afford to lose — that is true of any single drive, new or used.
